# 已锁定的决定

本文件覆盖整个重做。模块文档可以补充细节，不能推翻这里的句子。要改决定，先改本文件并改受影响的模块文档。

## 范围

原项目的玩法都要重做：地形、光照、生成、流体、全部方块、电路、活塞、家具、衣物、生物、寻路、碰撞、投射物、爆炸、掉落、粒子、时间、季节、天气、天空、生存属性、背包合成熔炉箱子发射器、音频、全部界面、新存档、模组、社区与公告、设置、图鉴与帮助、最多 4 名本地玩家。不做 VR。

施工顺序只决定先后：

1. 世界骨架：区块、光照、生成、挖掘放置、格子碰撞、一名玩家。
2. 内容数据：方块、物品、配方、掉落、语言。
3. 界面：主菜单到游戏内 HUD、背包、合成、对话框、图鉴、帮助。
4. 生物与生存：生成、行为、寻路、骑乘、船、饥饿、体温、睡眠、疾病、战斗。
5. 机械与环境：电路、活塞、家具、衣物、流体、四季、天气、天空、粒子、爆炸。
6. 多人：分屏、手柄。
7. 线上与模组：社区、外部内容、公告、模组导入与管理。

做到第 1 步可以运行，但不算移植完成。禁止把第 5 步及之后标成「本期不做」或从文档删除。

## 技术

- 引擎：Godot 4.7 .NET，C#。桌面目标框架 `net8.0`，安卓导出条件目标框架 `net9.0`。工程文件里的 Sdk 版本与本机编辑器一致（当前 `4.7.0-beta.2`）。编辑器若改写补丁号，保留编辑器的结果。
- 桌面渲染默认 `gl_compatibility`，以便更多显卡能打开骨架。安卓使用 `rendering_method.mobile=mobile`。换成 `forward_plus` 只能作为 Windows 导出选项，并且文档写明需要重启。禁止在运行中切换渲染器。
- 窗口、输入、音频、控件、骨骼动画用 Godot。地形网格、方块光、流体、电路、格子碰撞、格子寻路用 C#。不使用 OpenXR。
- 正式资源走 Godot 导入。模组在运行时读 PNG、glTF 和数据文件，不走编辑器导入器。
- 模型统一 glTF。着色器用 Godot 着色器语言重写。音频用 Ogg 或 Wav。禁止把 `.vsh`、`.psh`、Collada、FLAC 当作加载格式。

## 明确不做

- 不读旧世界、旧 `Project.xml`、旧区块 `.dat`。不保证旧种子生成同一张图。
- 不加载 `.scmod`。不实现 Harmony、Jint、游戏内编译 C#。
- 不做商城，不做应用内网页支付。
- 不做浏览器导出。Godot 4 的 C# 不能导出 Web。
- iOS 不与 Windows、Linux、安卓同级交付。
- 四名玩家可以分屏，可以各自使用手柄。不能把四套键盘和四只鼠标拆成四个设备。
- 不做 VR，不做头显，不接 OpenXR。没有头显的普通窗口就是玩法画面。

## 模组边界

已发布的游戏内可以导入、删除、启用、停用、排序模组压缩包。作者不需要游戏源码和 .NET。模组脚本是 GDScript，只调用模块文档列出的回调，只接收该模组自己的数据。禁止把场景根节点交给模组。关闭模组后，安装包里的 C# 保持原样。
