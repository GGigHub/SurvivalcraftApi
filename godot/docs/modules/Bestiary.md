# 图鉴与帮助

代码目录：条目数据放在 `assets/` 或 `scripts/Items/` 能加载的数据里。界面在 `scenes/ui/`。

原项目：生物图鉴、合成谱、帮助话题。

## 必须

- 图鉴条目来自 [Creatures.md](Creatures.md) 的生物表，不在界面里再写一份名单。
- 合成谱来自 [Items.md](Items.md) 的配方，点一条能看到材料和结果。
- 帮助话题覆盖移动、挖掘、合成、电路、生存这些玩家会卡住的内容。话题是数据文件，方便翻译。

## 禁止

- 把帮助写成代码里的长字符串散落在多个界面。
- 图鉴里展示一种游戏里不能生成的占位生物，除非缺口表写了它未完成。

## 完成标准

从主菜单或游戏内能打开图鉴、合成谱和帮助。生物表增加一种后，图鉴不用改界面代码就会出现它。
