# 物品与容器

代码目录：`scripts/Items/`。界面在 `scenes/ui/`。

原项目：背包、创造栏、合成表、工作台、熔炉、箱子、发射器、桶、工具耐久。

## 必须

- 物品 id 稳定。方块对应的物品和方块 id 的关系写在数据里，不要散落在 UI 代码里。
- 原游戏的合成表要迁入。工作台和背包合成的差别按原规则。
- 熔炉消耗燃料并产出。燃料热度和燃烧时间读方块表的 FuelHeatLevel、FuelFireDuration。只匹配 RequiredHeatLevel 大于 0 的单材料配方，进度每秒增加 0.15，满 1 消耗一份原料并放入产物。发射器存一叠物品，旁边的按钮按下时朝朝向的空格弹出一件并放成方块。见 [Electricity.md](Electricity.md)。
- 箱子和玩家背包容量、堆叠规则与原游戏一致。
- 工具有耐久，该损坏的会损坏。耐久读方块表的 Durability。挖掘成功后，手里耐久大于 0 的工具磨损 1，磨损到上限就从背包消失。

## 禁止

- 在界面脚本里写合成匹配。界面只显示 `scripts/Items/` 算出的结果。
- 用 Godot 的 ItemList 数据当作存档源。存档读的是 C# 库存。

## 完成标准

玩家能合成、熔炼、把东西放进箱子、让发射器射出物品。重新进入世界后容器里的东西还在。
