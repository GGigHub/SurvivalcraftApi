# 生存属性

代码目录：`scripts/Player/`。

原项目：`ComponentVitalStats`、`ComponentHealth`、`ComponentSleep`、`ComponentSickness`、`ComponentFlu`、`ComponentFactors`。饥饿、体力、体温、湿度、睡眠、疾病、等级经验都在这里。

## 必须

- 生存模式启用这些数值。创造模式按原游戏关掉会妨碍建造的惩罚。
- 食物、衣物、火、水、天气会改变对应数值。
- 死亡有原因，掉落按原规则处理，然后重生。
- 经验和等级如果原游戏有界面和效果，就保留，不要当成可删的装饰。

## 禁止

- 用 Godot 的生命条节点自己减血，和 C# 数值各算一遍。
- 只做饥饿和生命，把体温、湿度、睡眠、疾病留空还不写缺口。

## 完成标准

不吃东西会饿，寒冷和潮湿会体现在数值上，能睡觉并度过夜晚，生病会有后果。存档后这些数值还在。
