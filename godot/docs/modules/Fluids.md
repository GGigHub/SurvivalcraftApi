# 流体

代码目录：`scripts/World/`。

原项目：水和岩浆是方块，有深度，会流动，并和电路、爆炸、生物互动。

## 必须

- 水和岩浆都是区块里的格子，不是 Godot 粒子海，也不是着色器假水面铺满世界。
- 流动规则在 C#。流动后把受影响的区块标脏。
- 水下视线、游泳、溺水和岩浆伤害要接到 [Bodies.md](Bodies.md) 与 [Survival.md](Survival.md)。
- 桶能取水、取岩浆、倒出。物品见 [Items.md](Items.md)。

## 禁止

- 用 Godot 的 Water 材质或 GPU 流体插件代替格子水。
- 把流体做成不可挖掘的装饰。

## 完成标准

水会流向低处并形成深度。岩浆会伤到走进去的玩家。桶可以搬运这两种流体。
