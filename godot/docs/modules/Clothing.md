# 衣物

代码目录：`scripts/Items/`，外形在 `scenes/creatures/` 的骨骼附件上。

原项目：`Clothes.xml` 与 `ComponentClothing`，衣服穿在人物模型上，并有效果。

## 必须

- 衣物是物品，占装备槽。数据包含槽位、外观模型或贴图、防护或温度效果。
- 原游戏的衣物种类要进数据表。效果接到 [Survival.md](Survival.md)。
- 第三人称和界面里的人物预览都能看到已穿的衣服。第一人称可以只显示手上的物品。

## 禁止

- 用换一整套人物场景来模拟换衣服。
- 衣物只改图标、不改模型和数值。

## 完成标准

穿上和脱下会改变外形和对应数值。存档后重新进入，穿着还在。
