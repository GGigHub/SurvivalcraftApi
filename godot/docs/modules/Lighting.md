# 光照

代码目录：`scripts/World/`。

原项目：每个格子 0 到 15 的光，阳光从顶向下传播，写进顶点色。

## 必须

- 光照是格子数据，范围 0–15。
- 阳光和方块光分开存储。合成方式：阳光柱 `Sky` 只由从上往下的遮挡决定；横向漏光记在 `SunGlow`；火把、岩浆和点亮的灯记在 `BlockLight`。三者都是 0–15。每走一格减 1，水再多减 1。顶点色的 RGB 只负责生物群系和朝向，不乘时间。透明度通道存阳光曲线，第二套 UV 的 X 存方块光曲线。着色器亮度为 `max(阳光曲线 × 昼夜, 方块光曲线)`，所以夜里火把不跟着太阳变黑。
- 改一个方块后，只重算受影响的柱或区块，并标记相应网格为脏。
- 昼夜改变环境光时，已加载区块的顶点色要更新。规则见 [Environment.md](Environment.md)。

## 禁止

- 用 Godot 的 DirectionalLight3D、烘焙光照或 SDFGI 代替方块光。方向光可以只做太阳圆盘的视觉，不能决定格子明暗。
- 把光照做成全屏后处理来冒充方块光。

## 完成标准

洞穴里会变暗，火把或发光方块能照亮周围，挖开顶上的方块后阳光落下来。这些变化来自格子光，不是实时灯。
