# 世界生成

代码目录：`scripts/World/`。

原项目：`TerrainContentsGenerator` 系列，用噪声、温度、湿度决定生物群系和地表。每个水平柱还有地表高度。

## 必须

- 新世界有种子。同一安装包、同一版本、同一种子必须生成同一地形。
- 不承诺和旧版生存战争的种子结果一致。禁止写旧档转换器来凑出旧地形。
- 生成在后台进行，不能卡住主线程整帧。
- 群系、地表方块、矿石、树和初始结构的规则可参考旧代码，但写成新的数据加 C#。草地方块上会按种子散落草丛（编号 19），树干和树叶占住的格子不长草。群系名单以能覆盖原游戏出现过的地貌为准，缺一种就要在本文件列出，不能默默少做。
- 平坦世界作为一种生成模式保留。

## 禁止

- 用 Godot 的地形节点或 HeightMapShape 代替区块生成。
- 只生成一种草地加石头就结束本模块。

## 完成标准

生存世界能按种子生成不同群系、矿脉和树。重新开一局同一种子，已探索区域的方块一致。平坦世界没有这些起伏。
