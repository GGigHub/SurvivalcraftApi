# 生物

代码目录：逻辑在 `scripts/Creatures/`，骨骼和动画在 `scenes/creatures/`。

原项目：多种模型组件（人、四足、鸟、鱼等）、行为组件、生成、掉落、骑乘。动画既有骨骼剪辑，也有过程式步态和 IK。

## 必须

- 行为、仇恨、掉落、生成写在 C#。场景只负责网格、骨骼和动画剪辑。
- 原游戏图鉴里的生物都要有数据。缺一种就写进本文件缺口表。默认缺口表为空。
- 过程式走路可以在 C# 里改骨骼姿态。不能假设一个 AnimationPlayer 循环就等于旧的四足步态。
- 骑乘、船、挤奶、下蛋、羊群、逃离、攻击这些行为按原游戏有的种类做，寻路走 [Pathfinding.md](Pathfinding.md)。
- 外观用 glTF。禁止把 Collada 加载器搬进来。

## 禁止

- 把 AI 写进 GDScript 或动画回调里碰世界规则。
- 每种生物一个复制粘贴的玩家角色场景，只改贴图。
- 用 NavigationAgent3D。

## 完成标准

图鉴中的生物能生成，能走、能被打死、能掉物品。至少一种可骑乘，船能在水上开。重新进入世界后，已生成且应保存的生物还在。
