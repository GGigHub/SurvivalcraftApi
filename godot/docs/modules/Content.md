# 内容管线

代码目录：导入资源在 `assets/`。加载代码在使用它的模块里，路径规则以本文件为准。

原项目：`Content.zip` 与模组资源按路径覆盖，`ContentManager.Get<T>` 按后缀选择读取器。

## 必须

- 随游戏发布的模型、贴图、音频、界面、语言放在 `assets/`，用 Godot 导入。
- 语言文件用翻译键，不要把中文写死在 C# 里。至少提供原游戏已有的中文和英文。
- 模组资源不进 `assets/`，不要求用户用编辑器重新导入。运行时用 Godot 的图像和 glTF 接口读取文件。
- 同名内容的覆盖顺序是：游戏本体，然后按模组加载顺序覆盖。规则实现放在 [Mods.md](Mods.md)，本文件只规定路径和格式。

## 禁止

- 在运行时解一条自研的内容读取器链去替代 Godot 导入。
- 把旧 `Content.zip` 原样当作 Godot 的资源包而不经过格式约定。

## 完成标准

换一张 `assets/` 里的方块贴图，重新导出后游戏里变了。一个模组 PNG 能在不重新导出游戏的情况下盖住同名贴图。
