# 电路

代码目录：`scripts/Simulation/`。

原项目：`SubsystemElectricity` 和 51 个 `ElectricElement`。导线传电，逻辑门、锁存、延迟、按钮、压力板、灯、发射器、活塞、引爆都在这条模拟里。

## 必须

- 电是格子上的信号，在 C# 里按 tick 模拟。不要用 Godot 的可视脚本或粒子表示通断。
- 原有元件都要有对应行为和方块 id：与、或、非、与非、或非、异或、延迟、可调延迟、锁存、计数、真值表、存储体、数模、模数、按钮、开关、压力板、感光、测温、测湿、运动检测、电池、灯、导线、穿过方块的导线、发射器、引爆、火药桶、门、活板门、栅栏门、活塞、告示牌电信号、家具电元件。
- 元件连到 [Blocks.md](Blocks.md) 的方块 id。缺一个元件就记在本文件末尾的缺口表，默认缺口表为空，表示全做。
- 模拟和渲染分开。亮灯只改方块外观或顶点色。

## 禁止

- 用 Godot 的可视着色器闪烁冒充电路。
- 只做导线加一个门就结束。
- 让模组替换电路核心循环。模组只能通过 [Mods.md](Mods.md) 的回调得知某个公开事件。

## 完成标准

玩家可以用导线把按钮连到灯、门和活塞上，延迟和锁存的结果与原游戏规则一致。51 类元件都有方块和模拟，或本文件有明确的缺口和原因。
