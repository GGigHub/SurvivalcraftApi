# 社区

代码目录：`scripts/App/`。界面在 `scenes/ui/`。

原项目：社区内容浏览、外部内容、用户、公告、市场相关管理器。这是在线目录和下载，不是商城。

## 必须

- 用 HTTP 拉取公告和内容列表。界面用 Control。
- 下载的内容进入游戏可管理的文件，而不是写进安装包。
- 失败时显示原因，保留上一次成功的列表或明确的空状态。
- 如果服务器地址还没定，把地址放在设置或单独配置，不要写死一个假想的生产域名还假装已接通。

## 禁止

- 做商城、应用内支付、WebView 套网页。
- 为了社区功能去导出浏览器版。

## 完成标准

主菜单能打开公告和内容列表。没有网络时游戏仍能进入已有世界。下载下来的模组或世界包可以在对应管理界面里看到。
