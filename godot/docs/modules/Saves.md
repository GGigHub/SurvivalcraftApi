# 存档

代码目录：`scripts/App/` 负责列表和读写入口，区块字节布局放在 `scripts/World/`。

原项目：`WorldsManager`、`Project.xml`、区块 `.dat`，带多代版本转换。

## 必须

- 新格式自带魔数和版本号。读不到版本就拒绝，并告诉玩家这不是本游戏的世界。
- 一局世界包含：种子、生成模式、时间、天气、玩家、库存、箱子、生物、区块、已用模组名单。
- 游戏内能新建、继续、删除。导出成一个包可以后做，但列表和继续必须先有。
- 模组改变了方块 id 时，世界记录用过的模组。缺少模组时要提示，不能静默把格子读成空气还不说明。

## 禁止

- 读取或写入旧的 `Project.xml`、`Region *.dat`。
- 把 Godot 的 `PackedScene` 当作世界存档。
- 实现 `VersionConverter113To114` 这类旧档升级。

## 完成标准

退出再进入，地形、玩家位置、背包和时间还在。把旧版生存战争的世界文件夹丢进来时，游戏拒绝并说明原因。
