# 家具

代码目录：`scripts/Items/` 存设计数据，设计器界面在 `scenes/ui/`。

原项目：玩家在设计器里拼小型方块，得到可以放置的家具，家具可以带电，也可以打包分享。

## 必须

- 家具是玩家创作的小型结构，放进世界后走地形网格，不每个家具一个场景实例堆满世界。
- 设计器是 Control 界面，能摆放、旋转、保存、删除设计。
- 家具包可以导入导出。格式是新的，不读旧的家具包二进制，除非单独在本文件写明兼容范围。默认不兼容。
- 带电家具接到 [Electricity.md](Electricity.md)，不另做一套电。

## 禁止

- 用 GridMap 当设计器的数据模型。
- 把家具系统留成空菜单并声称模块完成。

## 完成标准

玩家能设计一件家具，放进世界，挖掉，再放回。带开关的家具能接通电路。家具包能在另一局导入。
