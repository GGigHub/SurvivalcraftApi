# 设置

代码目录：`scripts/App/`。界面在 `scenes/ui/`。

原项目：画面、声音、控制、界面缩放、性能、兼容模式、键位与手柄映射。

## 必须

- 音量、视距、界面缩放、键位、语言会保存，下次启动仍在。
- 渲染器选项只包括文档允许的值。桌面可以在 `gl_compatibility` 与 `forward_plus` 之间选择，安卓使用 mobile 或 gl_compatibility。修改渲染器后提示重启，本次会话不切换。
- 键位只改 [Input.md](Input.md) 里的动作。

## 禁止

- 做运行中销毁渲染器再新建的切换。
- 把 ANGLE、OpenGL ES 上下文创建搬进本工程。兼容问题交给 Godot 的渲染器和导出模板。

## 完成标准

改完音量和视距，重启后还在。改渲染器时游戏说明需要重新启动，并且不会在当前进程里换掉渲染器。
