# 战斗与粒子

代码目录：规则在 `scripts/Simulation/`。表现可以用 Godot 的 GPUParticles3D，但生成和伤害在 C#。

原项目：投射物、爆炸、掉落物、着火、经验、挖掘裂纹、各类粒子子系统。

## 必须

- 箭、子弹、投掷物命中格子或身体时结算伤害和掉落。命中检测用格子射线和身体体积，不用网格射线当唯一依据。
- 爆炸会破坏方块、推动身体、点燃可燃物，并触发电路里该被引爆的元件。
- 掉落物能被拾取，掉进岩浆或火里按原规则处理。
- 挖掘进度和裂纹是表现，进度数值在 C#。
- 原游戏有的武器和爆炸物都要能用，物品 id 见 [Items.md](Items.md)。

## 禁止

- 用 RigidBody3D 模拟每一支箭的弹道碰撞。
- 用粒子系统的碰撞来决定是否造成伤害。

## 完成标准

近战、弓箭和枪能造成伤害。火药桶和爆炸会挖开地形并更新光照。掉落物可以捡起。着火会蔓延到可燃方块并伤害生物。
