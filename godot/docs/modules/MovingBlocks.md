# 移动方块

代码目录：`scripts/Simulation/`。

原项目：`SubsystemMovingBlocks`，活塞推动一组方块，推动过程中方块离开格子，结束时写回地形。

## 必须

- 移动中的方块不是独立刚体。位置由 C# 插值，碰撞仍按格子或按移动体的占位计算，见 [Bodies.md](Bodies.md)。
- 和电路的活塞元件共用一套推动规则。
- 推动结束、被挡住、推动实体时都要有确定结果，不能把方块复制成两份。

## 禁止

- 用 AnimatableBody3D 或 RigidBody3D 逐个推动方块。
- 在活塞动画期间用 PhysicsServer 重建整块区块的碰撞体。

## 完成标准

活塞能推出和拉回一组方块，中途挡住时停下，结束后地形格子和网格一致。
