# 地形

代码目录：`scripts/World/`。

原项目：`SubsystemTerrain`，区块水平 16、高 256，格子是 int 数组，脏区块在 CPU 组网格后画三次（不透明、镂空、透明）。

## 必须

- 默认区块水平 16、高 256。要改尺寸，先改本文件，并同时改光照、存档和生成文档。
- 世界是区块字典。玩家附近加载，远离卸载。
- 改过的区块标记为脏，在 C# 里组好顶点，一次提交给 RenderingServer。
- 顶点至少带位置、贴图坐标和顶点色。方块光写在顶点色里，见 [Lighting.md](Lighting.md)。
- 按相机丢掉背向的面。不透明、镂空、透明分开画。
- 半砖、十字植物、门使用 [Blocks.md](Blocks.md) 里登记的形状，不在地形模块里写死某一种方块。

## 禁止

- GridMap。
- 一个方块一个 MeshInstance3D、StaticBody3D 或 Area3D。
- 把组好的网格保存成 `.tscn`。
- 用 PhysicsServer 的凹多边形网格当地形碰撞。碰撞见 [Bodies.md](Bodies.md)。
- 为了省事只做一种实心方块就宣告地形完成。

## 完成标准

能走出已生成区域，区块会加载和卸载。挖掉或放上任意已登记形状的方块后，只有脏区块重建网格，其余区块不动。透明方块不会挡住后面的不透明面排序到错层。
